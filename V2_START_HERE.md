### Important limitation
This GitHub ZIP **is not the previously generated 32 MB `Forest_Spirit_Shrine_V2_English_Optimization_Kit.zip`**. The connected GitHub uploader cannot transfer that binary ZIP or the original GLB assets. This repository ZIP supplies the **English instructions and reference diagrams**. For continued optimization, also provide Claude the `Forest_Spirit_Shrine_Complete_Project.zip` that it produced earlier (which contains the actual GLB models and scripts). The high-resolution concept PNG was in the earlier ZIP and is not hosted in this GitHub branch; attach it separately when available. Do not claim this branch includes the original binary 3D models.

### Get started
1. Download this branch ZIP.
2. Send Claude **both** the extracted branch ZIP and its previous original completed scene ZIP.
3. Paste the text from `docs/V2_CLAUDE_CONTINUATION_PROMPT.txt`.
4. Require a real editable Blender file, not only a procedural GLB or source script.
5. After the hero scene passes visual review, finish the full environment and produce a new final `Forest_Spirit_Shrine_V2_Complete_Project.zip`.

### Quality gap
The prior version has valid geometry but still resembles a primitive prototype: smooth balloon-shaped tree canopies, over-regular shrine ring, flat sparse ground, repeated path slabs, weak depth/lighting and too many aerial-only previews. The previous delivery did not contain a validated editable `.blend` file.

**Target hardware:** Windows laptop, integrated GPU, 16 GB system RAM. Godot 4 Compatibility; measure 720p performance rather than promising an untested FPS.

**Branch isolation:** The repository's main branch is unchanged.

## Reference hierarchy
- `specs/scene_manifest.json` fixes dimensions and positions.
- `references/MASTER_TOPDOWN.svg` fixes spatial layout.
- `references/views/` and `references/SHRINE_TURNAROUND.svg` are consistent construction views.
- `references/STYLE_DIRECTION.svg` is a simplified style illustration.
- The original **painted** concept PNG, if supplied, is the high-quality final look target.

No copyrighted game assets should be copied.
