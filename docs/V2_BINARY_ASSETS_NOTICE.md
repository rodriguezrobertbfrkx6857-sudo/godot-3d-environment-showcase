# Binary assets — what is and is not hosted here

This branch **does not contain** the original 32 MB V2 English Optimization Kit binary ZIP and **does not contain** the original full GLB environment.

The original full 3D scene was delivered in a separate archive named `Forest_Spirit_Shrine_Complete_Project.zip`, created by Claude. To carry out true V2 asset continuation, Claude needs that original archive alongside this GitHub download.

If a future automation or connected environment can upload binary files, publish the complete binary package as a GitHub Release asset. Do not label this reference branch ZIP as the identical complete 3D project.

The construction SVGs and written guidance are sufficient to inspect design targets but not to modify the missing 3D geometry by themselves.
