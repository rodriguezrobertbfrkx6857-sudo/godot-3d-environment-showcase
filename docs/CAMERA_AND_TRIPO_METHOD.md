# Orthographic Turnarounds and Multi-Angle Scenes

A beautiful concept illustration is not a geometrically consistent 3D scene.

For a full environment, fix coordinates and object dimensions FIRST. Make a top-down plan, create eight camera views from one actual scene, and ensure the same trees, columns, pathways and props persist in every shot. A camera named EAST stands east and looks west, rather than looking east.

For a single object like the shrine, create front, back, left, right and top orthographic views with consistent scale. In Tripo, use up to four consistent object-specific images; do not attempt to reconstruct an entire forest from those images.

In Blender, use the manifest for absolute placement and compare rendered turnarounds to the enclosed schematic guides. The separate style illustration governs color and mood only.
